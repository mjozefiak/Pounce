# Execution plan: Phase 0 scaffold (Pounce MVP)

Source doc: .ai/specs/2026-10-31-pounce-launcher-mvp.md
Branch: feat/scaffold (base: main)

## Goal

Ship Phase 0 of the MVP spec: an installable, empty menu-bar app built from a Swift package with the
plugin contract in place, CI for build, tests and format lint, a signed DMG release workflow, and the
SQLCipher decision made before any database exists.

## Scope

- `Package.swift` (`swift-tools-version: 6.2`, macOS 26, Swift 6 mode) with the targets `PounceKit`,
  `PounceCore`, `PouncePersistence`, `PounceApp` (executable product `Pounce`) and their test targets.
  Only `PounceApp` uses `.defaultIsolation(MainActor.self)`.
- `PounceKit`: the plugin contract from the spec's API Contracts section plus the DI ports, each
  contribution with an empty default.
- `PounceApp`: `PluginRegistry` (empty list), `PluginHost` (lifecycle, states, enable/disable, per-source
  time budget), `AppCoordinator`, `StatusItemController` (template SF Symbol, menu with plugin commands,
  About and Quit), the DI port implementations, DEBUG-only QA launch arguments.
- `Resources/Info.plist` (`LSUIElement`, `app.pounce.Pounce`, `LSMinimumSystemVersion` 26.0) and
  `Resources/Localizable.xcstrings` (`en` + `pl`).
- `scripts/make-app.sh`, `scripts/make-dmg.sh`, `scripts/make-signing-cert.sh`.
- `.github/workflows/ci.yml` (build, test, TSan for `PluginHost`, format lint) and
  `.github/workflows/release.yml` (PR / manual build of the signed DMG as an artifact, tag-triggered
  publish).
- Spike 0.4: GRDB with SQLCipher through SwiftPM, recorded in `docs/decisions/0001-sqlite.md`.
- Docs: `docs/signing.md`, `docs/qa.md`, ADR, `AGENTS.md` kept accurate.

## Non-goals

- No plugins (`AppsPlugin`, `ClipboardPlugin`, `FilesPlugin` arrive in Phases 1-3).
- No panel, hotkeys, Settings window, onboarding, KeyboardShortcuts dependency (Phase 1).
- No `ranking.sqlite` schema or `UsageRepository` (step 1.6); Phase 0 only proves the GRDB variant.
- No app icon, DMG background art or landing page (Phase 4).
- No tags, no GitHub Releases, no repository settings changes.

## Implementation Plan

### Phase 1: Package and contracts (spec 0.1, 0.1b)

1.1 `Package.swift`, `Resources/Info.plist`, `Resources/Localizable.xcstrings`, menu bar shell
(`StatusItemController` with template symbol, About and Quit), Info.plist and catalog smoke tests.
1.2 `PounceKit` contracts and DI ports with defaults; `PluginRegistry`, `PluginHost`, `AppCoordinator`;
unit tests on test plugins (enabled plugin activates, disabled one deactivates, a throwing `activate()`
fails alone, an over-budget source does not block another, a disabled plugin exposes no commands).
1.3 DEBUG-only QA launch arguments (temporary data root, in-memory Keychain, no hotkeys, forced
appearance, menu preview) and `docs/qa.md`.

### Phase 2: Persistence spike (spec 0.4)

2.1 GRDB with SQLCipher through SwiftPM in `PouncePersistence`, the encrypted/plain open helper, the
spike test (no key fails, right key reads, wrong key fails, file has no plaintext), ADR
`docs/decisions/0001-sqlite.md`.

### Phase 3: Packaging, CI and signing (spec 0.2, 0.3)

3.1 `scripts/make-app.sh` and `scripts/make-dmg.sh` (ad-hoc locally, identity from the environment in CI).
3.2 `.github/workflows/ci.yml` (build, test, TSan for `PluginHost` tests, format lint).
3.3 `.github/workflows/release.yml` with the temporary-keychain import of "Pounce Release", the DMG
artifact on PRs and manual runs, the designated-requirement check, the tag-triggered publish job and
Gatekeeper release notes; `scripts/make-signing-cert.sh` and `docs/signing.md`.
3.4 `AGENTS.md` and README updated to the new layout.

## Risks

- The `xcode-27` runner label is a public-preview image; if it disappears the fallback is `macos-26`
  with Xcode 26.x, which the code must keep compiling on (no macOS 27-only APIs).
- SQLCipher ships as a dynamic framework; the app bundle must embed and sign it, and library validation
  under the hardened runtime must accept it.
- The self-signed certificate is untrusted on runners; signing may need a runner-only trust setting.
