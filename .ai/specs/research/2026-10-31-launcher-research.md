# Research: how fast launchers work on macOS (2026-10-31)

Input for [the MVP spec](../2026-10-31-pounce-launcher-mvp.md). Four parallel research tracks were summarized here; claims marked *(unverified)* came from model knowledge, not from a source.

## File search
- **Raycast** dropped Spotlight (MDQuery) for its own indexer in the 2.0 rewrite (May 2026). Its default index covers filenames only, in `~` and `/Applications`, and skips dotfiles, `.gitignore`d paths, `node_modules` and caches. Sources: [blog](https://raycast.com/blog/the-new-raycast), [manual](https://manual.raycast.com/file-search.md).
- **Alfred** still uses Spotlight, so its results inherit Spotlight's gaps: [Alfred KB](https://alfredapp.com/help/troubleshooting/indexing/spotlight).
- **Cardinal** is the best reference design ([repo](https://github.com/cardisoft/cardinal), MIT, Rust).
  - Index: a slab of nodes with parent pointers plus interned names.
  - Updates: FSEvents with `FileEvents | NoDefer`.
  - Persistence: snapshot plus the last event ID, so a restart catches up on changes instead of rescanning.
  - Requires Full Disk Access.
- **Initial scan:** `getattrlistbulk` scanned 409k files in 0.52 s with a warm cache on an M1 Pro ([healeycodes](https://healeycodes.com/maybe-the-fastest-disk-usage-program-on-macos)). Avoid `searchfs`, which is slow on APFS ([tempel.org](https://blog.tempel.org/2017/07/apfs-and-fast-catalog-search.html)).
- **Memory:** roughly 100 MB per 1M files ([voidtools FAQ](https://www.voidtools.com/faq/)).
- **Matching:** fzf-style scoring; [nucleo](https://github.com/helix-editor/nucleo) (Rust) or [FuzzyMatch](https://swiftpackageregistry.com/ordo-one/FuzzyMatch) (Swift).

## App search
- **Discovery:** use a live `NSMetadataQuery` on `com.apple.application-bundle`, plus a directory scan as a fallback because Spotlight can be disabled ([Apple forum](https://developer.apple.com/forums/thread/822349)).
- **Names and icons:** localized names from `displayName(atPath:)`, the English `CFBundleName` as an alias, and icons loaded lazily into a cache.
- **Ranking:** Raycast's documented order is alias > title fuzzy > keywords > frecency ([manual](https://manual.raycast.com/search-bar), [useFrecencySorting](https://developers.raycast.com/utilities/react-hooks/usefrecencysorting)).
- **Permissions:** none needed.

## Clipboard history
- **Capture:** poll `changeCount`; there is no change notification. [Maccy](https://github.com/p0deje/Maccy/blob/master/Maccy/Clipboard.swift) is the reference implementation (MIT).
- **Skip private data:** respect the [nspasteboard.org](http://nspasteboard.org) types `ConcealedType`, `TransientType` and `AutoGeneratedType`.
- **Pasteboard privacy:**
  - Introduced as a preview in macOS 15.4, with the `accessBehavior` and `detect…` APIs ([mjtsai](https://mjtsai.com/blog/2025/05/12/pasteboard-privacy-preview-in-macos-15-4/)).
  - Not enforced by default as of macOS 26 / 27.2 betas ([kopi #4](https://github.com/code-devanshu/kopi/issues/4)).
- **Auto-paste:** posting ⌘V through CGEvent needs the PostEvent/Accessibility grant. Grants break when the code signature changes ([Maccy #811](https://github.com/p0deje/maccy/issues/811)).
- **App Store:** App Review rejects `CGEvent.post` paste under guideline 2.4.5 ([Apple forum](https://developer.apple.com/forums/thread/820594)).
- **Encryption:** Raycast keeps clipboard history in an encrypted local database ([security docs](https://developers.raycast.com/information/security)). GRDB supports SQLCipher through `usePassphrase` (GRDB README).

## Stack
- **Raycast 2.0 resource use:** a Swift host plus a WebView and a Node backend use about 350–450 MB at idle. The WebView has to be kept warm to show instantly ([deep dive](https://www.raycast.com/blog/a-technical-deep-dive-into-the-new-raycast)).
- **Native Swift + AppKit `NSPanel`:** a few ms to show a pre-built panel and about 30–60 MB at idle *(unverified estimates)*. Tauri needs [tauri-nspanel](https://github.com/ahkohd/tauri-nspanel). Electron has open panel bugs ([#41874](https://github.com/electron/electron/issues/41874)).
- **Hotkeys:** [KeyboardShortcuts](https://github.com/sindresorhus/KeyboardShortcuts) wraps Carbon `RegisterEventHotKey` and needs no permission. Option-only hotkeys break on macOS 15 ([forum](https://developer.apple.com/forums/thread/763878?page=2)).
- **Other open-source launchers:** [Sol](https://github.com/ospfranco/sol) (React Native, MIT), [Loungy](https://github.com/MatthiasGrandl/Loungy) (GPUI, archived), [ueli](https://github.com/oliverschwendener/ueli) (Electron).
