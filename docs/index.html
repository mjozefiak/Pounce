Find any app, file or clipboard entry in a keystroke.

Pounce is a native macOS launcher with just three things: app search, file search with its own index, and an encrypted clipboard history that pastes straight into the app you were using.

Download for macOS Source on GitHub

macOS 26 or later · Apple silicon · No account, no telemetry

Three things, done fast.

Press the shortcut and type. Results come from Pounce's own in-memory indexes, so the panel opens instantly and answers as you type.

  • App search

    Fuzzy matching finds apps by any part of the name: “vsc” finds Visual Studio Code. Pounce learns which results you pick and moves them up, without ever overruling a better match.

  • File search

    Its own index of file and folder names in your home folder and Applications, kept fresh with FSEvents instead of Spotlight. Names only: Pounce never reads what is inside your files.

  • Clipboard history

    Text, links, rich text, images and files from the last 30 days (up to 1000 entries), encrypted on disk with a key in your Keychain. Skips password managers and concealed items. Return pastes into the previous app.

Native and accessible

  • Swift, AppKit and SwiftUI with the system's Liquid Glass; light and dark mode follow macOS.
  • VoiceOver labels and announcements, Reduce Motion, Reduce Transparency, Increase Contrast and a text-size setting.
  • Every feature can be turned off in Settings, and its data erased.
  • English and Polish, following your system language.

Only the permissions a feature needs.

Pounce never asks for a permission on its own. Settings → Permissions shows each one with its state and a button to System Settings. Nothing leaves your Mac.

Accessibility

Lets the clipboard history paste into the app you were using. Without it, Return copies the entry and you paste yourself.

Optional

Full Disk Access

Lets file search include Desktop, Documents, Downloads and iCloud Drive without asking about each folder. Without it, you can add those folders one at a time.

Optional

Clipboard access

macOS can ask before an app reads the clipboard. Allow Pounce in Privacy & Security so the history keeps recording.

Optional

Keychain

The clipboard history's encryption key lives in your login keychain. No permission is needed; macOS may ask once to allow access.

Install in a minute.

  1. Download Pounce.dmg and open it.
  2. Drag Pounce onto the Applications folder.
  3. Open Pounce from Applications. A paw appears in the menu bar and the welcome screen walks you through the shortcut and each feature; every step can be skipped.

First launch: Gatekeeper

Pounce is signed with its own stable certificate, so macOS keeps your permissions across updates, but it is not notarized by Apple. The first time you open it, macOS blocks it. To allow it once:

  1. Open Pounce and close the warning.
  2. Open System Settings → Privacy & Security and scroll down.
  3. Click Open Anyway next to the message about Pounce, then confirm with your password or Touch ID.

Or build it from source

Requires Xcode 27 (Swift 6.4).

git clone --recurse-submodules https://github.com/mjozefiak/Pounce.git
cd Pounce
swift package resolve --disable-keychain
scripts/make-app.sh    # dist/Pounce.app

Questions.

How do I use ⌘Space if Spotlight has it?
On first launch Pounce suggests ⌃⌥Space and shows how to turn off “Show Spotlight search” in System Settings → Keyboard → Keyboard Shortcuts → Spotlight. You can record any shortcut in Settings → General.
Does Pounce search inside files?
No. It matches file and folder names only, from its own index on your Mac. Folders like node_modules, .git, caches and ~/Library are left out by default.
What does the clipboard history keep?
Up to 30 days or 1000 entries, encrypted with SQLCipher. Entries copied in ignored apps (password managers by default) and items marked concealed are never recorded. You can pause recording or clear the history any time.
Does it send anything over the network?
No. There is no account, no analytics and no update check.
Why does macOS warn me when I open Pounce?
Notarization needs a paid Apple developer account, and Pounce is a free project. Allow it once with Open Anyway (see Install), or build it yourself from the source.
